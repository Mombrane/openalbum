# Phase 6 — 网页

**Status:** planned

## Goal

把 React 占位页换成可用界面，并走通主要路径。

## In scope

设计说明已经写明的网页：登录与注册、个人库瀑布流、上传、详情、关键词与自然语言搜索、共享册与口令权限、API Key 的创建和吊销。

## Out of scope

社交动态、原生 App、开放 Agent 市场、多租户计费、站内大模型。

## Domain touches

不把业务规则写进网页。网页调用同一后端。

## Acceptance

以设计说明的网页范围和 MVP 验收为准。原文阶段 Spec 未包含在可用产物中，这里不补写实现步骤。

## Depends on

Phase 5。
