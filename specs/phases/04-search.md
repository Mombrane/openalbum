# Phase 4 — 检索

**状态：** planned  
**依赖：** Phase 3

## 目标

主人可以用关键词，或用自然语言，在自己的个人库里找照片。关键词匹配描述与标签；自然语言走 pgvector 召回。

## 范围内

- 检索用例：过滤（时间、标签、状态）与关键词
- 语义检索：查询文本先经嵌入网关变成向量，再在 `photo_embeddings` 上召回
- 只返回调用者有权看到的个人库照片
- 结果带缩略图访问信息与已有元数据
- 数据量起来之后的 IVFFlat / HNSW 索引：本阶段可以先顺序扫描或小数据索引，但要在本文件记下切换条件
- 设计稿中的 `POST /photos/search` 语义；最终路径在本阶段定稿

## 范围外

- 跨用户的公开搜索
- 共享册内搜索（若需要，在 Phase 5 追加，不在本阶段假装已经支持）
- 以图搜图（除非实现时发现与文本嵌入是同一条路径且不扩大范围）

## 领域触点

`domain/search`：查询值对象、结果排序需要的领域规则、检索端口。  
嵌入的生成复用 Phase 3 的嵌入网关，不在领域层发 HTTP。  
照片是否属于该主人，复用照片库与身份的规则。

## 验收

- [ ] 关键词能命中描述或标签中的词，且不返回别人的照片
- [ ] 自然语言查询能召回语义相近、状态允许展示的照片（测试可使用假嵌入，保证排序稳定）
- [ ] 尚未 `ready` 且没有嵌入的照片不会被当成语义命中
- [ ] 检索接口在 JWT 与 API Key 下行为一致
- [ ] 领域层边界检查仍然通过

## 依赖

Phase 3 为 `done`。
