# 限界上下文概览

本页只转述定稿设计说明里已经写明的上下文，不增加新的业务能力。

## identity

人类用邮箱和密码登录网页。Agent 使用用户创建的 API Key，请求头为 `Authorization: Bearer <apiKey>`。Key 只存哈希，可命名、吊销，并查看末次使用时间。

## library

每个用户有一个默认个人库。只有本人和持有其有效 Key 的 Agent 可以读写。照片包含原图与缩略图、拍摄时间、地点、描述、标签、来源、向量，以及状态 `processing` / `ready` / `failed`。

## album

共享册用链接和口令进入。角色是册主、可上传、只读。口令兑换短期会话，不明文写入日志。没有权限时返回 403，并且不泄露册是否存在。

## search

在同一套权限模型里做关键词检索和自然语言检索。召回使用向量。

## 分层

后端依赖只能向内：接口层 → 适配层 → 领域层。DAO 与网关实现领域定义的端口。领域层禁止引入 HTTP、SQL、S3 或外部 SDK。
